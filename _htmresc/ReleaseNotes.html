STM32CubeWBA Firmware Package V1.11.0 / 28-October-2026

Main Changes

Official Release of STM32CubeWBA Firmware package supporting STM32WBA20xx, STM32WBA23xx, STM32WBA25xx, STM32WBA50xx, STM32WBA52xx, STM32WBA54xx, STM32WBA5Mxx, STM32WBA55xx, STM32WBA62xx, STM32WBA63xx, STM32WBA64xx and STM32WBA65xx devices

Security

- Update MCUboot V1.7.2.41

- Update AppliCfg V1.1.7

- Keys of OEMuRoT can be updated

Connectivity

- LinkLayer

- Improve the footprint by dynamically allocating the link layer data RAM.

- The Link Layer RAM is now sized by the application according to the link layer configuration : maximum number of concurrent state machines and BLE features supported.

- The libraries with the static 20 link allocations are removed (i.e. LinkLayer_BLE_Basic_20_links_V3_0.a, LinkLayer_BLE_Basic_20_links_V3_0p.a and LinkLayer_BLE_Basic_Plus_20_links_V3_0.a)

- Library split: LinkLayer_802_15_4_Vx.a → Mac15_4.a + LinkLayer_802_15_4_Vx.a; concurrent lib split into Mac15_4_Concurrent_BLE_xxx.a + LinkLayer_BLE_xxx_802_15_4_Vx.a; new porting layers mac_radio_port.c (Zigbee) and thread_radio_port.c (Thread). Customers linking these libs must update.

- BLE

- Support of the Randomized Resolvable Private Address feature on all STM32WBAx devices.

- Support of the LL Extended Feature Set and Monitoring Advertisers features on STM32WBA5x and STM32WBA6x devices.

- Update of the BLE stack in alignement with the Bluetooth Core Specification v6.3 and the Bluetooth TCRL pkg104.

- BLE Audio

- Update of the BLE Audio Framework in alignement with Bluetooth TCRL pkg104

- Thread

- Integrate Platform Security Architecture (PSA) APIs into the OpenThread stack for improved security.

- Zigbee

- New callbacks functions available at application side to track the joining state of a device.

- Include several fixes at the stack and link layers, enabling long-term tests to complete without memory exhaustion errors.

- Adding new applications : Zigbee_OccupSensing_Server_SED_WithTempCalib,Zigbee_PressMeas_Server_SED_Persist,Zigbee_TempMeas_Server_SED_LSI2.

- Removal of some previous applications not heavily used : Zigbee_Basic_xx ,Zigbee_Diagnostic_xx,Zigbee_MeterId_xx,Zigbee_PowerConfig_xx,Zigbee_PressMeas_xx.

- BLE Zigbee

- Refactor Zigbee Direct BLE services to align with the specification, simplify porting, and improve flexibility and maintainability while preserving CubeMX compatibility

Drivers

- Support of STM32WBA20xx, STM32WBA23xx, STM32WBA25xx, STM32WBA50xx, STM32WBA52xx, STM32WBA54xx, STM32WBA55xx, STM32WBA5Mxx, STM32WBA62xx, STM32WBA63xx, STM32WBA64xx, STM32WBA65xx and STM32WBA6Mxx devices

- Update CMSIS devices to include latest corrections

- HAL/LL Drivers available for all peripherals

- HAL: ADC, COMP, CORTEX, CRC, CRYP, DMA, EXTI, FLASH, GPIO, GTZC, HASH, HCD, HSEM, I2C, ICACHE, IRDA, IWDG, LPTIM, OTFDEC, PCD, PKA, PWR, RAMCFG, RCC, RNG, RTC, SAI, SMARTCARD, SMBUS, SPI, TIM, TSC, UART, USB, USART, WWDG, XSPI

- LL: ADC, BUS, COMP, CORTEX, CRC, DLYB, DMA, EXTI, GPIO, HSEM, I2C, ICACHE, IWDG, LPTIM, LPUART, PKA, PWR, RCC, RNG, RTC, SPI, SYSTEM, TIM, USART, USB, UTILS, WWDG

- Update HAL/LL drivers to include latest corrections

- HAL CRYP : SA0076 fully fixed

- BSP Drivers : Update STM32WBA55G-DK1 and STM32WBA65I-DK1 to include latest corrections
